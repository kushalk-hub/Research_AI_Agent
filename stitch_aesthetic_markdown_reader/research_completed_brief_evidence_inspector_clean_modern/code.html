Executive Summary

In multi-megabase genomic sequence analysis, canonical quadratic self-attention architectures encounter hardware I/O ceilings when context windows expand beyond 65,536 base pairs (bp). While flash-attention kernel fusions substantially reduce memory bandwidth overhead, asymptotic quadratic FLOP scaling remains prohibitive for chromatin-conformation and whole-chromosome modeling (≥ 106 bp).

Conversely, continuous-time structured state-space models and selective SSMs like Mamba demonstrate deterministic linear runtime with constant memory footprints during autoregressive rollout, maintaining fidelity at 107 token lengths.

Complexity & Scaling Dynamics

Standard Transformer self-attention computes an unbounded soft dynamic lookup matrix, requiring explicit storage or recomputation across all chromosomal loci. For regulatory distal enhancers operating across 2+ megabases, memory footprint quickly bottlenecks standard GPU clusters.

Key Empirical Takeaways

Zero-shot Sensitivity: Transformer models retain slight edge on rare transcription factor motif recognition where dense cross-attention between flanking sequences is essential.
